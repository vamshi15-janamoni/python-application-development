# Module 5 - Python Application Development

A Flask REST API with SQLite database integration, CRUD operations, validation, documentation, and endpoint testing.

## Features
- Flask REST API
- Routing and HTTP methods
- SQLite database
- CRUD operations
- Basic request validation
- Pytest API tests
- API documentation

## Structure
```text
python-application-development/
├── app/
│   └── main.py
├── database/
│   └── .gitkeep
├── tests/
│   └── test_api.py
├── docs/
│   ├── API_DOCUMENTATION.md
│   └── LEARNING_NOTES.md
├── requirements.txt
└── README.md
```

## Run
```bash
pip install -r requirements.txt
python app/main.py
```

## Test
```bash
pytest
```
