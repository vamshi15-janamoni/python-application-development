# Module 5 Learning Notes

- **Flask:** Python web framework for web applications and REST APIs.
- **Routing:** Connects URLs and HTTP methods to Python functions.
- **GET:** Read data.
- **POST:** Create data.
- **PUT:** Update data.
- **DELETE:** Remove data.
- **SQLite:** Lightweight relational database.
- **CRUD:** Create, Read, Update, Delete.
- **Validation:** Checks incoming API data.
- **Testing:** Pytest verifies API behavior.
